# Ye Chat Backend

Backend корпоративного кросс-платформенного приложения.

## Architecture

Проект построен как модульный монолит на NestJS.

## Modules

### Database
Отвечает за подключение к PostgreSQL через Prisma.

### IAM
Отвечает за идентификацию и авторизацию пользователей.

### Users
Отвечает за пользователей и их профили.

### Chat
Отвечает за чаты, сообщения и WebSocket-соединения.

### CRM
Отвечает за интеграции с внешними CRM.

### Audit
Отвечает за журналирование важных действий.

## Database

PostgreSQL используется как основная база данных.

Prisma используется как ORM и источник схемы базы данных.

## Roles

В системе существуют три системные роли:

- ADMIN
- MANAGER
- EMPLOYEE

Роли создаются через Prisma seed.
